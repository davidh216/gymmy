# Build #9: what to check on your iPhone

Install from TestFlight, then go through these. Each one is something only a real phone can show.

## Sign in with Apple
- [ ] Gyms tab → Create account → **Sign up with Apple** works, and the Gyms tab then asks you to pick a username.
- [ ] Sign out, then **Sign in with Apple** gets you back into the same account.

## Reminders
- [ ] Profile → Reminders → turn on **Training days**; iOS asks for permission once.
- [ ] Set the time a few minutes ahead on today's weekday; the reminder arrives and names today's session.
- [ ] Log a workout today; no training reminder fires later today.

## Widget
- [ ] Long-press the Home Screen → **+** → Gymmy → add the small and medium sizes.
- [ ] Lock Screen → Customize → add the Gymmy widget.
- [ ] Finish a workout; the widget's streak, week dots and next session update.
- [ ] Tapping the widget opens Gymmy.

## Setup prompts on Today
- [ ] After your first workout, Today asks about reminders; after the second, Apple Health; after the third, height and weight. "Not now" hides each one.

## Apple Health calories
- [ ] Profile → Apple Health → **Save calories to Health** (if shown) → Allow.
- [ ] Finish a workout; the Fitness app shows active calories on it.

## Deleting an Apple account (only with a spare account)
- [ ] Profile → Delete account on an account made with Sign in with Apple. Afterwards, Settings → your name → Sign in with Apple no longer lists Gymmy.
