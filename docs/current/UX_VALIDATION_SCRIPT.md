#### **Perceivable**

## 📊 **USER TESTING METHODOLOGY**

### **Test Participant Recruitment**
- **7 Segments**: 5-10 users per fitness segment
- **Experience Levels**: New users, existing users, power users
- **Platforms**: iOS, Android, Web users
- **Accessibility**: Users with assistive technology needs

### **Testing Protocol**
```markdown
## User Testing Session Protocol

### Pre-Session (5 minutes)
- Welcome and introduction
- Explain testing purpose and process
- Obtain consent for recording
- Brief questionnaire about fitness background

### Main Session (30-45 minutes)
- Complete onboarding flow
- Explore team building features
- Experience gacha system
- Navigate collection management
- Think-aloud protocol throughout

### Post-Session (10 minutes)
- Satisfaction questionnaire
- Feature discovery assessment
- Usability rating scales
- Open-ended feedback collection
```

### **Data Collection**
- **Quantitative Metrics**: Task completion rates, time to completion, error rates
- **Qualitative Feedback**: User comments, pain points, suggestions
- **Satisfaction Scores**: 1-10 ratings for different aspects
- **Feature Adoption**: Which features users discover and use
