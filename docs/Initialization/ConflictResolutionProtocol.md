# CONFLICT RESOLUTION PROTOCOL

## LEVEL 1: AGENT-TO-AGENT
- Direct communication between specialist agents
- Document discussion in shared notes
- Reach consensus within 1 iteration
- If no consensus → escalate to Level 2

## LEVEL 2: MASTER AGENT MEDIATION
- Master agent reviews conflict details
- Makes technical decision based on architecture
- Documents decision rationale
- Updates relevant documentation
- If architectural change needed → escalate to Level 3

## LEVEL 3: VIBECODING DECISION
- Master agent presents problem + recommended solutions
- vibecoding makes final call
- Decision becomes new standard for project
- All agents updated with new guidelines
